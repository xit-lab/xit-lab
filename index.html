Research Areas

Neural ECC Decoder

Neural decoding combines error-correcting codes with machine learning to recover information from noisy signals, balancing accuracy, complexity, and adaptability.

RL ECC Construction

Reinforcement learning explores and optimizes error-correcting code structures, balancing error resilience, code rate, and decoding complexity.

Quantum Error Correction

Quantum error correction protects quantum information from noise and decoherence by encoding logical qubits across physical qubits and using error syndromes to guide recovery.

LLM Text Watermark

Text watermarking embeds detectable signals into language model outputs to support provenance verification and source attribution while preserving text quality.

AI Image Detection

AI image detection analyzes visual and statistical patterns to distinguish synthetic images from real photographs, supporting media authenticity and digital forensics.
